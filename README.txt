PORTFOLIO WEBSITE - HTML AND CSS ONLY

Files:
- index.html: page structure/content
- style.css: design and responsive styling

How to use:
1. Keep index.html and style.css in the same folder.
2. Open index.html in your browser, or open the folder in VS Code.
3. Update the email, LinkedIn profile, and sample projects in index.html.

Note: This version intentionally contains no JavaScript. Interactive API features such as loading live GitHub repositories require JavaScript or a server-side solution, so they are not included in this HTML/CSS-only version.
